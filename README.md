# Child Monitoring App  

A powerful **Django Interface** designed to monitor and manage swarm devices, providing real-time insights and automated functionalities for enhanced safety and supervision.  

## Features  

### Device Monitoring  
- **Heartbeat Status**: Check swarm heartbeats and track the last online status (default threshold: 3 minutes).  
- **Live Notifications**: Access real-time notifications from swarm devices.  

### Usage Tracking  
- **App Usage Insights**: Monitor time spent on thier mobile apps by swarm victim.
- **Keylogging**: Review android views extracted and keylog content for detailed activity monitoring.  

### Accessibility RootKit Integration  
- **RootKit Download**: Download the Accessibility RootKit app from a secret endpoint.  
- **Deletion Detection**: Notifies if the RootKit is removed from a device.  

### Automated Screening and Alerts  
- **Content Screening**:  
  - Batch process logs using CRON jobs to identify inappropriate content from User monitored logs.  
  - Sends Email alerts to designated recipients for flagged content detection.
